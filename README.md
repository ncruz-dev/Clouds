# Clouds
## Azure Lab: 
Aprender Azure sin tarjeta de crédito y sin miedo a la factura. 💸
He creado Azure Lab: un simulador de Azure que funciona en tu ordenador, gratis y de código abierto. Puedes crear máquinas virtuales, romper una red o dejarte un clúster encendido todo el fin de semana… y no pasa nada.
Qué incluye:
☁️ Un portal con máquinas virtuales, App Service, Storage, redes, Key Vault, AKS y más
💻 Cloud Shell con az, kubectl, terraform, git y docker
🔁 Azure DevOps: repos, pull requests y pipelines YAML
🎓 Una academia de 13 niveles y 47 laboratorios que se corrigen solos, de «qué es la nube» a CI/CD
Para probarlo solo necesitas Docker:

git clone https://lnkd.in/duisHBpS
cd azure-lab
docker compose up -d --build

…y abres localhost:8090 en el navegador.
Lo he pensado para quien está aprendiendo cloud o DevOps, como yo: practicar sin consecuencias es la forma más rápida de aprender. Si lo pruebas, cuéntame qué echas en falta. Y si te sirve, una ⭐ en GitHub ayuda a que llegue a más gente.
👉 https://lnkd.in/duisHBpS
(La interfaz y los laboratorios están en español).

Recuerda. La práctica hace al maestro.
